# MJCode 0.5.0-beta

首个公开发布版（`0.1.0` → `0.5.0-beta`）。这一版的核心，是把「长任务跑不稳」背后的几条根因一次性清掉。

---

## 前端 / 交互

- **思考态可见**：运行中显示「已思考 Ns · 已收 N 字」。推理模型思考好几分钟时，界面不再是一行静止的「思考中…」——这直接减少了「以为卡死 → 按 Esc → 把正常任务杀掉」的连锁。
- **设置页新增「网络与超时」**：三层超时可视化调整，并显示每个值的来源（你设置的值 / 环境变量 / 默认值）与可调区间。填 5 秒会被收到 10 秒下限并**回显**，不会静默吞掉。
- **修复整页崩溃**：消息里出现「产出文件」卡片时，渲染层抛 `IconFile is not defined` → 顶层 ErrorBoundary 把整页换成崩溃页。根因是一个漏掉的 import（该文件带 `@ts-nocheck`，`tsc` 检查不到）。
- **Enter 不再打断当前任务**：运行中按 Enter 改为「入队」，卡片上提供「直接发 / 修改 / 删除」三个动作。
- **Esc 收窄**：只在没有输入焦点时触发全局停止，避免在弹层里按 Esc 把整轮任务停掉。
- **崩溃后自动恢复**：界面重启后提示「界面刚刚自动重启过一次」，会话历史不丢。

## 业务逻辑 / Agent 引擎

- **超时改为「空闲语义」三层**（首字节 90s / 空闲 300s / 单轮总时长 15min）
  - 判断依据从「总共花了多久」改成「多久没有动静」：只要还有数据在流——包括推理模型的思考内容、工具调用分片、甚至 SSE 心跳注释行——就一直等。
  - 推理模型（mimo 等）在思考阶段长时间不输出正文，此前会被 120s 总时长直接腰斩，现在不会了。
  - 三层数值全部可在设置页调整；环境变量 `MJ_STREAM_*` 仍可用于临时覆盖。
- **上下文压缩改按体积取尾部**
  - 旧实现按「条数」保留最后 6 条；模型一轮并发读 8 个文件时，末尾连续 8 条工具结果会把切点顶到历史末尾，压缩**直接放弃**——但调用方照样清零预算窗口，于是每 5 轮空转一次、一分钱不省（实测 21 轮烧掉 1.6M tokens）。
  - 现在按 token 预算取尾部（窗口 25% / 激进 15%）+ 最多保留一半轮的硬约束；压缩无收益时不再清零窗口，改为硬截断 → 挂起。
  - 实测：并发 8 个工具的场景，压缩收益从 **0%** 变成 **54%**。
- **子代理 / 定时任务通道**：从 180s 硬顶改为「首字节 + 总时长」，与交互路径同源。非流式请求没有中间数据可观察，所以不设空闲层（已在代码与文档注明）。
- **服务端上游地址 SSRF 防护**：协议白名单 + 私网/链路本地/元数据端点拒绝；同时用显式开关保住「本机 Ollama」这条主路径。

## 稳定性与可观测性

- **进程级崩溃不再是黑箱**：新增 `render-process-gone` / `child-process-gone` / `unresponsive` 捕获，写入本地诊断 JSONL（含活跃 runId 与 trace 尾部），并自动 reload。
- 自动 reload 有防死循环闸（1 分钟内最多 3 次），超限只记录不重载——避免一个必崩的渲染缺陷变成无限重载把诊断文件刷满。
- **界面无响应只记录、不重载**：重载等于把用户正在跑的任务杀掉，这个决定权留给用户。

## 测试与质量

- **142 套件全绿**（新增 4 个：`stream-guard` / `compact-tail-budget` / `crash-guard` / `stream-settings`）。
- 每个新门禁都配了「预期为红」的反向用例；关键门禁做过变异验证（例如删掉 `IconFile` import，渲染冒烟必须转红）。
- `tsc --noEmit` 0 error；文档事实门禁（引用可解析 / 数字现算比对）0 错误 0 警告。

## 安装说明（重要）

- **未签名、未公证**。本机只有 `Apple Development` 证书（不是 `Developer ID`），发布构建已显式禁用签名，否则会产出无法分发的包。
  - 首次打开：**右键 → 打开**；或到「系统设置 → 隐私与安全性」点「仍要打开」。
- **仅 arm64（Apple Silicon）**。Intel Mac 需自行从源码构建。
- 本地数据落在 `~/Library/Application Support/mj-code-desktop/`。

## 已知限制

- Linux 沙箱（bubblewrap）未在任何真机验证过；相关套件在 macOS 上按平台跳过——**「测试绿」不代表 Linux 隔离已验证**。
- `file:preview` 尚未做根目录白名单（已在威胁模型登记）。
- 非流式通道没有空闲语义（响应体到齐前没有任何可观察数据）。
- 长任务把 21 轮做到 1.6M tokens 的场景，仍需在真机上复跑一次确认端到端行为。
